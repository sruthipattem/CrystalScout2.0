Developer API

The same models behind a FastAPI REST service with token sign-in, so CrystalScout can sit inside a DFT workflow, a LIMS or a lab notebook.

Start the API

python -m uvicorn api.main:app --port 8000

Then open http://{{ host }}:8000/docs for interactive Swagger docs. Use any of the four CrystalScout accounts to sign in.

Sign in

POST /auth/login returns a bearer token (12 h).

Send the token

Authorization: Bearer <token> on every call.

Score or screen

CIF upload, formula estimate, descriptors or a full screen.

Endpoints

GET/healthstatus, no sign-in
POST/auth/loginget a token
GET/auth/mewho am I, role
GET/modelsall metrics
POST/predict/cifupload a CIF
POST/predict/formulaσ from a formula
POST/predict/descriptors5 descriptors in
POST/design/labFormula Lab
POST/design/adviseDopant Advisor
POST/design/recipesynthesis recipe
POST/design/checkreality check: exists?, feasible?, structure, prediction
POST/design/cifCIF for any formula (real or generated)
POST/screenrun a screen
GET/runs, /runs/{id}saved runs

Python example

import requests
API = "http://{{ host }}:8000"
tok = requests.post(f"{API}/auth/login", json={"username": "scientist", "password": "…"}).json()["access_token"]
H = {"Authorization": f"Bearer {tok}"}

print(requests.post(f"{API}/predict/formula", json={"formula": "Li6PS5Cl", "space_group": "F-43m"}, headers=H).json())
with open("my_material.cif", "rb") as f:
    print(requests.post(f"{API}/predict/cif", files={"file": f}, headers=H).json()["sigma"])
top = requests.post(f"{API}/screen", json={"band_gap_min": 1.0, "rank_model": "crystalscout", "top": 10}, headers=H).json()
best = requests.post(f"{API}/design/advise", json={"formula": "Li6PS5Cl", "space_group": "F-43m"}, headers=H).json()["best"]
print(best["formula"], best["sigma_text"], requests.post(f"{API}/design/recipe", json={"formula": best["formula"], "batch_g": 5}, headers=H).json()["equation"])

A ready-to-run client is in api/example_client.py. Inside the web app there is also a lightweight JSON endpoint: GET /api/estimate?formula=Li3InCl6 (uses your browser session).
